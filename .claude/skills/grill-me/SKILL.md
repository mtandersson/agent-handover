# Grill me

Interview the user one decision at a time. Walk each material branch of the
design tree, resolve dependencies between choices, and provide a recommended
answer with every question.

Use the interactive user-question API when available. If a question can be
answered by inspecting the repository or another available source of truth,
inspect it instead of asking.
